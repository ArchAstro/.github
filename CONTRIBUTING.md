# Contributing to ArchAstro projects

Thank you for taking the time to contribute.

## Before you start

- Read the repository README and any project-specific contributing guide.
- Use an issue or discussion for substantial behavior or design changes before
  investing in an implementation.
- Report vulnerabilities to security@archastro.ai. You can also use GitHub
  private vulnerability reporting when the repository enables it.

## Pull requests

- Keep each change focused and explain the behavior or problem it addresses.
- Add or update tests for changed behavior.
- Run the repository's documented checks before requesting review.
- Document user-visible behavior, limitations, and security or privacy effects.
- Do not include credentials, private data, or internal ArchAstro information.

Project-specific contribution instructions take precedence over this default.
